# ⏱️ 25분 타임어택 해커톤 진행 보드

**주제 뽑기부터 QR 투표, 시상식까지 화면 하나로 진행하는 미니 해커톤 대시보드**

👉 **바로 사용하기: https://hyeseon-cpu.github.io/gdgoc-mini-hackathon/**

GDGoC KNU에서 실제로 **5명이 25분 동안 진행한 해커톤**에서 쓴 페이지입니다.
설치나 로그인 없이 브라우저에서 바로 동작해요. (QR 투표만 Firebase를 사용해요)

## 진행 순서

| 단계 | 기능 | 설명 |
|---|---|---|
| STEP 1 | 🎰 아이디어 가챠 | **타겟 × 상황** 슬롯을 돌려 "누가, 어떤 상황에서 쓰는 서비스"인지 정해요. 슬롯은 따로 리롤할 수 있어요 |
| STEP 2 | 🙋 미션 보드 | 뽑은 주제를 참가자에게 배정해요. 한 명씩 즉시 뽑기, 전원 일괄 뽑기도 돼요 |
| TIMER | ⏱️ 제작 타이머 | 25분 카운트다운이에요. 1분 남으면 화면이 깜빡이고, 끝나면 알람이 울려요 |
| SHOWCASE | 🎤 발표 순서 뽑기 | 슬롯으로 발표 순서를 정해요. "다음 발표자"를 누르면 1분 발표 타이머가 바로 시작돼요 |
| STEP 3 | 📱 QR 모바일 투표 | QR을 띄우면 참가자가 각자 폰으로 1·2·3등을 골라요. 타이머가 끝나면 투표가 닫히고 결과가 집계판에 블라인드로 들어가요 |
| STEP 3 | 🗳️ 3·2·1 개표 방송 | 1등 3점, 2등 2점, 3등 1점 가중치 투표예요. **블라인드 모드**로 점수를 가린 채 입력하고, 개표 방송으로 한 표씩 공개해요 |
| AWARD | 🏆 시상식 | 드럼롤과 함께 하위 순위부터 공개하고, **TOP 3 스포트라이트 룰렛**으로 1등을 발표해요 🎉 |

## 📱 QR 모바일 투표

1. 집계판의 **QR 투표 열기**를 누르고 투표 시간(1~5분)을 골라요.
2. 참가자는 QR을 스캔해 **내 이름 → 1·2·3등**을 차례로 고르고 제출해요. 본인은 뽑을 수 없어요.
3. 타이머가 끝나거나 전원이 투표하면 자동으로 마감되고, 표가 집계판에 블라인드로 들어가요.
4. 그다음 **개표 방송 → 최종 결과 발표**로 이어가면 돼요.

**중복 투표 방지 (Firestore 보안 규칙으로 서버에서 검사)**
- **이름당 1표**: 투표지가 이름별로 저장되고, 한 번 들어간 투표지는 덮어쓸 수 없어요.
- **기기당 1표**: 같은 폰에서 다른 이름으로 또 투표할 수 없어요.
- **마감 시간 이후 투표 거절**: 폰 시계를 바꿔도 서버 시간 기준으로 막혀요.
- **마감·연장은 진행자 화면만 가능**: 진행자 브라우저만 아는 키로만 바꿀 수 있어요.
- 이미 투표한 이름은 참가자 화면에서 회색으로 표시돼요.

> QR 투표는 웹 주소(GitHub Pages)에서 열어야 동작해요. 파일을 더블클릭해서 열면 QR 투표만 빼고 나머지 기능은 그대로 쓸 수 있어요.

## 진행 팁

- **블라인드 모드를 추천해요.** 개표 방송에서는 1점과 2점 표만 공개하고 **3점 표는 시상식까지 봉인**해서, 마지막까지 1등을 알 수 없어요.
- QR 없이 카톡 DM이나 종이로 받은 표는 진행자가 +3 / +2 / +1 버튼으로 직접 넣어도 돼요. 블라인드로 입력할 땐 화면 공유를 잠깐 꺼두세요.
- 동점이면 3점 표를 더 많이 받은 사람, 그다음 2점 표를 더 많이 받은 사람이 앞서요.
- 참가자 이름, 주제, 표는 **브라우저에 자동 저장**돼서 새로고침해도 유지돼요. QR 투표를 쓸 때만 참가자 이름과 투표가 Firebase로 전송돼요.
- 헤더의 **키워드 편집**에서 타겟과 상황 키워드를 우리 모임에 맞게 바꿀 수 있어요.
- **AI용 프롬프트 복사** 버튼을 누르면 뽑은 주제로 바로 바이브 코딩을 시작할 수 있는 프롬프트가 복사돼요.

## 직접 쓰기

1. 위 링크로 접속하거나, `index.html`을 내려받아 브라우저로 열어요.
2. 참가자 이름 칸을 클릭해 이름을 입력해요.
3. 가챠 → 타이머 → 발표 → 투표 → 시상식 순서로 진행하면 끝이에요.

다른 챕터나 동아리에서도 자유롭게 가져다 쓰셔도 돼요 🙌

## 사용 기술

- 화면: Tailwind CSS (CDN), canvas-confetti, Phosphor Icons, Pretendard, Web Audio API(효과음 직접 합성)
- QR 투표: Firebase Cloud Firestore + 보안 규칙(`firestore.rules`), qrcodejs

## 내 Firebase로 쓰기

다른 모임에서 직접 운영하려면:

1. Firebase 프로젝트를 만들고 Firestore 데이터베이스를 생성해요.
2. `firebase-config.js`에 내 웹 앱 설정을 붙여넣어요.
3. `firebase deploy --only firestore:rules`로 보안 규칙을 배포해요.

로컬(`localhost`)에서 열면 Firestore 에뮬레이터(`firebase emulators:start --only firestore`)에 연결돼요.
